## Evidence boundaries

Fixture tests use temporary stores and injected native components. Installed mechanism probes use the actual service, protected state/pipe, launcher and Jobs with a fixed executable. Separate continuation-5 checks use the real sealed Deszo, its Tauri/Node chain, a physically consented diagnostic policy, native UI and profile writes. Stable controlling Deszo with owned attempts and provider-backed feature delivery remain missing evidence.

For each guarantee retain requirement → invariant → enforcement → failure test → independent evidence. Original failed reports and historical independent audits remain immutable. A production capability receipt must be bound to the exact installed trusted files digest; the ten passing probe scenarios do not authorize blanket activation.

## Human-dependent and engineering work

Fresh Windows Hello policy consent, real lock/unlock and sleep/reboot actions cannot be automated. They are not substitutes for the remaining engineering: worker repairs/timing/integration, build provenance, route coverage, real application topology and data/UI verification must be prepared and implemented first. Do not blame a missing physical confirmation for an unimplemented protocol or bypass bootstrap to break that dependency.

Only after all required native gates are valid may the authorized real pilot proceed. No push, merge or release is part of this task.
